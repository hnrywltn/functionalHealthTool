# Changes — May 22, 2026

## New Categories

- Added **Anatomy & Physiology** entity — lives in the sidebar alongside all other entity types and is fully cross-referenceable

## Labs / Biomarkers / Amino Acids

- **Normal Range** field is now a textarea — supports multi-line entries for ranges that vary by sex, age, or method

## Print / Save PDF

- New **Print** button on every detail page
- Opens a print-preview page in a new tab with a sortable field checklist — check or uncheck fields to include, drag to reorder
- Each section supports a free-text **notes** field for annotations that appear only in the printout
- Triggers the browser's native print dialog, which supports Save as PDF on all major platforms
