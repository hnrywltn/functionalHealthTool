# Changes — July 28, 2026

## Bug Fix: PDF download — stretched/garbled text on lines with curly quotes

- Anna reported a downloaded PDF looked correct in the app but had a line with stretched-out letter spacing after export.
- Root cause: PDF text is hand-laid-out with jsPDF's built-in `"helvetica"` font, which doesn't reliably support typographic punctuation (curly quotes, em/en dashes, ellipsis) pasted in from sources like Google Docs — any line containing those characters could render distorted in some PDF viewers even though on-screen (browser-rendered) text was unaffected.
- Fix: sanitize text to plain ASCII equivalents (curly quotes → straight quotes, em/en dash → hyphen, ellipsis → `...`, etc.) right before it's passed to jsPDF, in `components/PrintModal.tsx`. Only affects the generated PDF — the on-screen view is untouched.

No DB changes.

## Widened main content column

- Anna reported the main text area stayed a fixed width no matter how much she resized the window.
- Cause: the entity list, entity detail, tags, and references pages all wrap their content in a `max-w-3xl` (768px) container, which caps out well below typical window widths.
- Widened to `max-w-5xl` (1024px, +33%) in `app/[entity]/page.tsx`, `app/tags/[name]/page.tsx`, `components/EntityDetailClient.tsx`, and `components/ReferencesClient.tsx`. Left the homepage search box (`HeroSearch.tsx`) at its narrower width since it's a search widget, not a content-reading area.

No DB changes.

## Sticky Save/Cancel bar while editing

- Reported: on long entity detail forms, the Save/Cancel buttons live in the header at the top of the page, so editing anything further down required scrolling back up to save or cancel.
- Fix: while in edit mode, the header row (name field + Save/Cancel) now uses `position: sticky` so it pins to the top of the scroll area once you scroll past it, instead of scrolling out of view. No change to the header's behavior or appearance outside of edit mode. Change in `components/EntityDetailClient.tsx`.

No DB changes.
