# Changes — July 7, 2026

## Print / PDF

- Anna reported that printed pages / saved PDFs showed the text "about:blank" in the lower-left corner. This came from Chrome's built-in print header/footer, which always shows the page's real URL — the old implementation opened a blank popup window and wrote HTML into it before calling `window.print()`, so its URL was literally `about:blank`.
- The browser's print header/footer is an all-or-nothing setting controlled in the print dialog (no way for a page to selectively hide just the URL), and Anna didn't want to rely on a global browser setting that would also affect her other apps/sites.
- **Decision:** replaced the print-dialog flow entirely with real client-side PDF generation. The "Print" button is now "Download PDF" — it lays out the selected sections as real text objects with `jsPDF` (manual pagination via `splitTextToSize`) and triggers a direct file download. No browser print pipeline is involved, so there's no injected header/footer at all — just our own footer ("Health Reference · [date]"), which was already there.
- First pass rendered the PDF via an `html2canvas` snapshot embedded as an image, but Anna needs the text to be searchable/selectable in the saved PDF, so that approach was replaced with native text rendering (no `html2canvas` dependency needed).
- Added dependency: `jspdf`.

## New category: CE (Continuing Education)

- Added a new top-level entity type, **CE**, for tracking continuing education material. Fields: Description, Topic, Source, Notes.
- Source uses the same hybrid field as Lab Tests' Source — type freeform text (e.g. a conference/journal name) or search and link an existing Laboratory/Vendor record.
- Shows up automatically in the sidebar, home page category grid, and search — no other code changes were needed since entity types are fully config-driven in this app.
- Anna also asked for a file/reference-files field — this already works with no changes needed. The "References" drag-and-drop file section (added 2026-06-19) is generic across every entity type, so it was already available on CE records.

### Railway SQL

```sql
CREATE TABLE IF NOT EXISTS ce (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT NOT NULL,
  description TEXT,
  topic TEXT,
  source TEXT,
  notes TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
ALTER TABLE ce ADD COLUMN IF NOT EXISTS description TEXT;
```

## New category: Equipment

- Added a new top-level entity type, **Equipment**, for tracking physical devices/kits. Fields, in order: Classification, Description, Brand, Source, Instructions, Accessories, Maintenance, Contact, Cost, Notes.
- Source is a hybrid field (freeform text or linked record), scoped to **Vendors only** (not Laboratories, unlike CE/Lab Tests) since equipment is sourced from vendors, not labs.
- Accessories is a comma-separated list field, same pattern as Supplements' "Forms."

### Railway SQL

```sql
CREATE TABLE IF NOT EXISTS equipment (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT NOT NULL,
  classification TEXT,
  description TEXT,
  brand TEXT,
  source TEXT,
  instructions TEXT,
  accessories TEXT[],
  maintenance TEXT,
  contact TEXT,
  cost TEXT,
  notes TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
```

## New category: Affiliations

- Added a new top-level entity type, **Affiliations**, for professional organization memberships. Fields, in order: Description, Clinical Identifiers, Review Date, Cost, Source, Benefits, Links, Education, Notes.
- Source is a hybrid field scoped to **Vendors only**, same as Equipment.
- Review Date is a plain text field — there's no dedicated date-picker field type anywhere else in this app, so dates are entered as freeform text everywhere.

### Railway SQL

```sql
CREATE TABLE IF NOT EXISTS affiliations (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT NOT NULL,
  description TEXT,
  clinical_identifiers TEXT,
  review_date TEXT,
  cost TEXT,
  source TEXT,
  benefits TEXT,
  links TEXT,
  education TEXT,
  notes TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
```
