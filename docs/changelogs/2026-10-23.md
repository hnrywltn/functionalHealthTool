# Changes — October 23, 2026

## New entity: Contacts

- Anna emailed asking to add "Contacts" to the main menu, with these fields: Name, Title, Department, Company, Phone, Fax, Email, URL, Address, Date Met - Referral, Notes.
- Added a `contacts` entity type in `lib/entities.ts` (between CE and Diagnoses alphabetically, dusty-rose `#B5838D` dot). Name is the standard entity name field; the rest are form fields in her order. Address and Notes are multi-line, everything else single-line. "Date Met - Referral" is one free-text field, as she listed it.
- It shows up automatically everywhere entity types are listed: sidebar, home page cards/filters, search, relationships, tags.
- Tested locally: created a contact through the API, list and detail pages load with the new fields, search finds it, deleted it.

DB: new `contacts` table via `lib/migrate.ts` (applied locally). Like the other entity tables, it has an unused `description` column so the shared search query works.

```sql
CREATE TABLE IF NOT EXISTS contacts (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT NOT NULL,
  description TEXT,
  title TEXT,
  department TEXT,
  company TEXT,
  phone TEXT,
  fax TEXT,
  email TEXT,
  url TEXT,
  address TEXT,
  date_met_referral TEXT,
  notes TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
```
