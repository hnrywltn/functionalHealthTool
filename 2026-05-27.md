# Changes — May 27, 2026

## Rename: Labs → Lab Tests

- Entity type renamed from "Labs" to **Lab Tests** throughout the UI, sidebar, and search
- All existing relationships, tags, and attachments linked to labs records are preserved

## New Category: Laboratories

- New **Laboratories** entity — connect lab companies (Quest, LabCorp, specialty labs, etc.) to the Lab Tests they offer
- Fields: Description, Website, Phone, Address, Specialties, Notes

## Site-wide

- Categories are now alphabetical in the sidebar and on the hero page
- Sidebar is now resizable — drag the right edge to make it wider or narrower (160px–480px)
- Sidebar can be collapsed to a slim strip with the ‹ button in the header; click › to expand again
- Width and collapsed state are remembered across page loads

## Railway SQL

Run each statement separately in the Railway database console (it does not support PL/pgSQL `DO $$ ... $$` blocks):

```sql
ALTER TABLE labs RENAME TO lab_tests;
```
```sql
UPDATE entity_relationships SET entity_type_a = 'lab_tests' WHERE entity_type_a = 'labs';
```
```sql
UPDATE entity_relationships SET entity_type_b = 'lab_tests' WHERE entity_type_b = 'labs';
```
```sql
UPDATE entity_tags SET entity_type = 'lab_tests' WHERE entity_type = 'labs';
```
```sql
UPDATE entity_attachments SET entity_type = 'lab_tests' WHERE entity_type = 'labs';
```
```sql
CREATE TABLE IF NOT EXISTS laboratories (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT NOT NULL,
  description TEXT,
  website TEXT,
  phone TEXT,
  address TEXT,
  specialties TEXT,
  notes TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
```
