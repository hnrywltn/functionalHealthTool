# Changes — June 19, 2026

## Laboratories

- Added **Email** field to the Laboratory entity type

### Railway SQL

```sql
ALTER TABLE laboratories ADD COLUMN IF NOT EXISTS email TEXT;
```

## Supplements

- Added **Ingredients** field
- Added **Source (Where to Order)** field

### Railway SQL

```sql
ALTER TABLE supplements ADD COLUMN IF NOT EXISTS ingredients TEXT;
ALTER TABLE supplements ADD COLUMN IF NOT EXISTS source TEXT;
```

## Lab Tests

- Added **Indications** field
- Replaced Normal Range, Low Interpretation, and High Interpretation with a single **Ranges** field
- Added **Source** field — hybrid input that can be freeform text or a linked Laboratory/Vendor record (clickable link navigates to the record; edit opens a modal with search)
- Added **Cost** field
- Added **Instructions** field
- Added **FAQs** field

### Railway SQL

```sql
ALTER TABLE lab_tests ADD COLUMN IF NOT EXISTS indications TEXT;
ALTER TABLE lab_tests ADD COLUMN IF NOT EXISTS ranges TEXT;
ALTER TABLE lab_tests ADD COLUMN IF NOT EXISTS source TEXT;
ALTER TABLE lab_tests ADD COLUMN IF NOT EXISTS cost TEXT;
ALTER TABLE lab_tests ADD COLUMN IF NOT EXISTS instructions TEXT;
ALTER TABLE lab_tests ADD COLUMN IF NOT EXISTS faqs TEXT;
```

## References
